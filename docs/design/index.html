Rules that apply everywhere

Sign in with Linux accounts

PAM login with the machine's own users. Users without sudo see only what they may do; sudo users can do everything after unlocking with their password (unlocked for 5 minutes). Root can sign in only if allow_root = true.

One colour per section

Overview indigo, Terminal green, Files blue, Logs amber, Services red, Software violet, Users teal, Plugins pink. The rail, icons, tiles and file types reuse them.

Status colours stand apart

Running, warning, failed and info have their own tokens, so a failed service stays red in monochrome or distro-colour mode.

No grey divider lines

Separate things with spacing, tinted rows, tinted panels and hover highlights. Tables use soft zebra rows instead of hairlines.

Side panels, tabs inside

Services, Users, Logs, Plugins and Files open details in a right panel with tabs. On phones the same panel becomes a bottom sheet.

Preferences follow the account

Theme, language, colour mode, terminal options and dashboard layout are stored server-side per Linux user, so they follow you to any browser.

Distro aware

The rail and sign-in page show the distro logo read from /etc/os-release, with Tux as fallback. The distro colour can become the accent.

Plugins declare what they do

Each plugin lists its root commands, files, sockets and UI additions. Installing shows that list for consent. Plugin pages appear in the rail under Plugins.
