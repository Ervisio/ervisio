# Ervisio logo files

| Folder | What |
|---|---|
| `mark/` | The mark alone, transparent background. `dark` = for dark backgrounds, `light` = for light backgrounds. 16 to 1024 px. |
| `logo/` | Mark + name, transparent background, 64/128/256 px high. |
| `mono/` | One-colour versions (white, black). |
| `icon/` | App icons on a rounded square (black, white, indigo), and square avatars (for GitHub, social profiles). |
| `svg/` | The mark as vector files. |

Colours: indigo `#8B93FF` and green `#3DDC97` on dark backgrounds; `#4B53D6` and `#13A86B` on light ones. Name in Figtree ExtraBold, lower case, letter spacing −4.5%.
